# 고덕지도 한국어판 · 베이징 (Goduk Map KO)

중국 고덕지도(高德地图, Amap)는 중국어를 모르면 쓰기 어렵습니다.
이 앱은 **고덕 지도 타일 위에 한국어 안내를 얹은 베이징 여행용 지도**입니다.
서버·API 키 없이 동작하는 정적 웹앱(PWA)이며, 중국 현지 네트워크에서도 타일이 잘 뜹니다.

## 기능
- 🗺️ 고덕(高德) 지도 타일 (중국어 / 영어 글자 전환) + 한국어 장소 라벨
- 📍 베이징 주요 관광지·만리장성·쇼핑·맛집·공원·역/공항 40곳: 한국어 이름, 중국어 이름, 병음, 중국어 주소, 가까운 지하철역, 팁
- 🔍 한글·중국어·병음 검색, 카테고리 필터
- 🚕 **기사에게 보여주기**: 중국어 이름+주소를 전체화면 큰 글씨로
- 🧭 고덕지도 앱 / 애플지도로 바로 길찾기 딥링크, 중국어 이름·주소 복사
- ♥ 내 일정(즐겨찾기) 저장, 일정 전체를 중국어로 한 번에 보기
- 🗣️ 택시·길찾기·식당·결제·긴급 회화 24개 (크게 보기 지원)
- 💡 결제·VPN·예약·여권 등 여행 팁
- 📱 홈 화면에 추가(PWA), 앱 셸과 최근 본 지도 타일 오프라인 캐시
- GPS 좌표(WGS-84)를 고덕 좌표계(GCJ-02)로 자동 보정해 현재 위치가 어긋나지 않음

## 실행
빌드 과정이 없습니다. 아무 정적 서버로 폴더를 띄우면 됩니다.

```bash
# 로컬 미리보기
npx serve .          # 또는 python3 -m http.server 8080
```

배포는 GitHub Pages / Vercel / Netlify / Firebase Hosting 등 정적 호스팅 아무 곳이나 됩니다.
파일 프로토콜(`file://`)로 열면 서비스워커·위치 기능이 제한됩니다.

## 구조
```
index.html          앱 화면
css/style.css       스타일 (라이트/다크)
js/data.js          장소·회화·팁 데이터  ← 장소 추가는 여기만 고치면 됩니다
js/gcj02.js         WGS-84 ↔ GCJ-02 좌표 변환
js/app.js           지도·검색·시트·패널 로직
vendor/leaflet/     Leaflet 1.9.4 (로컬 포함, CDN 불필요)
manifest.json, sw.js, icons/   PWA
```

## 장소 추가하기
`js/data.js`의 `places` 배열에 항목을 추가합니다. 좌표는 **WGS-84(일반 GPS)** 기준으로 넣으면 앱이 자동 변환합니다.

```js
{ id: 'myplace', cat: 'food', ko: '한국어 이름', zh: '中文名', py: 'pinyin',
  lat: 39.9, lon: 116.4, addr: '北京市…', metro: '역이름(호선)', tip: '메모' }
```

## 주의
- 장소 좌표·주소·운영 정보는 참고용 근사치입니다. 휴관일·예약·요금은 방문 전 고덕지도나 Trip.com에서 재확인하세요.
- 지도 타일은 고덕(AutoNavi) 공개 타일 서버를 사용합니다. 개인 여행용으로만 쓰세요.
